# Política de Privacidade — Casa Pública da Charlie Echo

Esta é uma versão inicial e pública. A Casa Pública da Charlie Echo é destinada a apoio educativo, organização de ideias e orientação inicial.

## Dados enviados pelo usuário

Ao usar a área de IA para Estudantes, o usuário envia voluntariamente o texto da pergunta. Não envie dados pessoais sensíveis, segredo de justiça, documentos sigilosos ou informações profissionais confidenciais.

## Uso da API

As perguntas podem ser processadas por serviço de inteligência artificial por meio de uma função segura no Cloudflare Pages. A chave da API não fica no navegador nem no GitHub.

## Limite de finalidade

A finalidade é educativa e organizacional. A versão pública não é ambiente de atendimento jurídico sigiloso.

## Direitos do usuário

O usuário pode solicitar informações, correções ou esclarecimentos pelo canal institucional da Jus 9 Tecnologia Jurídica quando disponível.

## Versões futuras

Qualquer versão jurídica supervisionada deverá possuir regras próprias de privacidade, login, auditoria, controle de acesso, revisão humana e governança de dados.
