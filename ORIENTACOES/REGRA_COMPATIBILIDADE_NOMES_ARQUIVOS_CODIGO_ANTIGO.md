# Regra de compatibilidade antiga para nomes, arquivos e codigo

Aplicacao: Jus 9 Tecnologia Juridica  
Destino: Charlie Echo e I.As auxiliares  
Guardia tecnica: Charlie Fox  
Data: 2026-05-19

## Regra matriz

Os nomes de pastas e arquivos devem ser pensados para computadores e programas antigos.

Antes de criar ou renomear arquivo/pasta, Charlie Echo deve preferir:

- letras ASCII simples: `a-z`, `0-9`;
- underscore `_` como separador principal;
- nomes sem acentos;
- nomes sem espacos;
- nomes sem parenteses;
- nomes sem cedilha;
- nomes sem caracteres especiais;
- extensoes comuns e minusculas: `.md`, `.txt`, `.html`, `.css`, `.js`, `.json`, `.png`, `.jpg`, `.pdf`, `.zip`;
- nomes curtos quando possivel, sem perder clareza.

## Padrao recomendado

Usar:

```text
protocolo_whatsapp_v1_0.md
coracao_das_ias
arquivos_de_versoes
backend_inicial
relatorio_auditoria_2026_05_19.md
```

Evitar:

```text
Coração das I.As
Arquivos de Vessões
Relatório Final (novo).md
Versões até 10-05-2026.zip
Novo(a) Documento de Texto.txt
```

## Compatibilidade das paginas

As paginas publicas da Jus 9 Tecnologia Juridica devem continuar prioritariamente responsivas.

Ordem de prioridade:

1. Responsividade e leitura em celular.
2. Acessibilidade basica.
3. Compatibilidade de nomes de arquivos e rotas.
4. Codigo simples e progressivo.

## Linguagem de programacao no DNA e no PRIORITARIO

Nos repertorios ou pastas de DNA, PRIORITARIO, coracao, governanca sensivel e memoria estrutural, preferir linguagem mais antiga, simples e legivel:

- Markdown simples.
- Texto `.txt` quando for registro essencial.
- HTML sem dependencia desnecessaria.
- CSS simples.
- JavaScript puro e conservador quando necessario.
- Evitar ferramentas modernas quando o mesmo resultado puder ser obtido com texto, Markdown, HTML, CSS e JavaScript simples.

## Regra para renomear arquivos existentes

Antes de renomear arquivo existente, a I.A deve verificar se ha referencias em:

- HTML;
- CSS;
- JavaScript;
- Markdown;
- manifests;
- service workers;
- rotas publicas;
- documentos de governanca.

Se o arquivo for usado em site ou codigo, atualizar todas as referencias junto com o renome.

Se houver risco de quebrar rota, import, link publico ou historico importante, registrar em auditoria e pedir revisao humana.

## Regra para arquivos sigilosos

Arquivos de chave, API, cofre, WhatsApp, coracao ou documentos privados podem ter nome compatível, mas seu conteudo continua protegido.

Renomear nome nao autoriza leitura, publicacao, resumo revelador ou commit de segredo.

## Decisao padrao

Na duvida, usar nome ASCII simples, sem acento, sem espaco, com underscore, e registrar a razao.
